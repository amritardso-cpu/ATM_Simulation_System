# ATM Simulation System

# 1. Problem Statement

Traditional banking transactions require users to visit a bank or use a physical ATM. For learning and demonstration purposes, there is a need for a simple software system that can simulate basic ATM operations.

The **ATM Simulation System** is developed using Java to provide basic banking functions such as account authentication, balance checking, depositing money, withdrawing money, and viewing transaction history.

The system also performs basic validation to prevent invalid transactions and unauthorized access through PIN verification.

# 2. Scope of the Project

The scope of the ATM Simulation System includes the following:

1. User authentication using account number and PIN.
2. Checking the current account balance.
3. Depositing money into an account.
4. Withdrawing money from an account.
5. Checking whether sufficient balance is available before withdrawal.
6. Maintaining transaction history during program execution.
7. Providing a simple menu-driven interface.
8. Handling invalid transaction amounts.
9. Providing basic account security through PIN validation.

## 4. High-Level Features

# 1. User Authentication
The system verifies the account number and PIN before allowing the user to access ATM services.

# 2. Balance Inquiry
Users can check their current account balance.

# 3. Deposit
Users can deposit money into their account. The system rejects zero or negative amounts.

# 4. Withdrawal
Users can withdraw money from their account after entering a valid amount.

# 5. Balance Validation
The system checks whether the account has sufficient funds before processing a withdrawal.

# 6. Transaction History
The system records deposits and withdrawals and displays them as a transaction statement.

# 7. Basic Security
The system uses PIN validation and private account information to provide basic security.

# 8. Menu-Driven Interface
Users can select ATM operations from a simple console menu.

# 9. Input Validation
Invalid choices, invalid deposit amounts, invalid withdrawal amounts, and insufficient funds are handled by the system.

# 10. Exit
Users can safely exit the ATM system after completing their transactions.
